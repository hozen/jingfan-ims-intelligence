## 核心信息

### 展会规模
- 5万平米展示面积
- 180余家企业参展
- 近万名代表参会（31省+港澳）
- 同期"城镇水务技术与产品展示"

### 六大议题（"十五五"开局）

| 议题 | 核心内容 |
|------|----------|
| "十五五"规划贯彻落实 | 水安全、水资源配置 |
| 《供水条例》施行 | 6月1日正式实施 |
| AI+水务 | 水务大模型、AI智能体 |
| 排水系统综合治理 | "厂-网-河"一体化 |
| 韧性城市 | 智能内涝防治 |
| 城市更新 | 海绵城市、管道改造 |

### 重点参展商

- **深圳环境水务集团** — 六大解决方案、40+创新技术，"机器人+AI"水质检测
- **万朗集团** — AI+智慧水务全流程解决方案
- **舜禹股份** — 全链条智慧水务（水源-用户-污水-再生水）
- **三川智慧** — 智能水表+物联网

### 关键趋势

1. **AI水务爆发** — 大模型、智能体应用成为焦点
2. **国产替代** — 市政采购要求国产比例上升
3. **韧性城市** — 内涝防治成为城市建设重点
4. **新《供水条例》** — 6月1日实施，行业进入新发展阶段
