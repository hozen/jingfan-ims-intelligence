# 2026环博览会市场观察

> 第27届上海国际环博会 · 2026.04.13-15 · 上海

**状态：** ✅ 完成（持续跟踪）

## 核心发现

### 展会数据
- 1,987家展商，82,419名观众，17万平米
- E1馆（水与污水）：77家
- E3馆（监测与检测）：~200家
- 国际观众连续两年增幅超30%

### 竞争格局

| 威胁等级 | 公司 | 特点 |
|---------|------|------|
| 🔴 极高 | 江苏纽带智能 | 国产替代，价格30-50%低于Hach |
| 🔴 极高 | 首创环保/鸿泰华瑞 | 系统集成强 |
| 🟠 高 | 智易时代 | AI算法领先 |
| 🟠 高 | E20环境平台 | 平台型威胁 |
| 🟠 高 | 昕彤智能 | 智能化后起之秀 |
| 🟡 中 | 33家中小厂商 | 尚云互联/易环智能/盘古自动化等 |

### 趋势判断

1. **软件平台军备竞赛** — E+H FieldEdge最具威胁，远程诊断+生命周期管理，"卖传感器送软件"
2. **传感器+软件一体化** — 不卖软件卖服务，按数据量收订阅费
3. **智能化从采集到预测** — 预测性维护、AI异常检测
4. **国产替代加速** — 市政采购要求国产比例，价格优势明显

### 行动建议

- 加快软件平台建设（对标FieldEdge）
- 关注国产替代政策窗口
- 强化高端客户差异化

## 最新动态（2026.05.04）

### 🔴 重大：哈希荣膺"2026 IE环博奖"年度领军企业

在2026环博会期间举办的IE环博奖评选中，哈希从数百家环保企业中脱颖而出，荣获**"2026 IE环博奖"年度领军企业**称号。该奖项历经定向邀约、企业申报、材料核验、专家评审等多轮严格筛选，代表行业对哈希品牌影响力和技术实力的高度认可。

来源：[哈希官网](https://ibook.antpedia.com/124/n/627216-n.html)

### 🔴 重大：Veralto Q1 FY2026财报（2026.04.28发布）

| 指标 | Q1 FY2026 | 同比 |
|------|-----------|------|
| 营收 | **$14.22亿** | +6.7% |
| 净利润 | $2.54亿 | +12.9% |
| 稀释EPS | $1.02 | +13.3% |

**业务板块表现：**
- **水质管理（Water Quality）**：营收 $8.74亿，**+10.1%**（核心增长+3.8%），是集团增长引擎
- **产品质量与创新（PQI）**：营收 $5.48亿，+1.7%（核心-1.0%），表现疲软

**并购动态：**
- Q1完成收购 **In-Situ**（$4.35亿现金），补强水质监测产品线
- In-Situ主营：地下水/地表水监测传感器、探头、水质分析仪，与Hach现有OTT HydroMet产品线高度互补
- 季度后达成收购 **GlobalVision**（CAD $2.7亿），强化PQI板块
- In-Situ预计2025年营收约$8000万，毛利率50%，EBITDA利润率约15%，高个位数增长

**2026全年指引上调：**
- 核心销售增长：3.0%-4.5%（原：3.0%-4.0%）
- 调整后EPS：$4.20-$4.28（原：$4.10-$4.20）

### 🟠 哈希研发20周年庆典

2026环博会首日（4月13日），哈希在E1馆举办"**哈希中国研发20周年盛大庆典**"，线上同步直播。哈希自2006年起在中国布局本地研发，累计推出多款本土定制产品，标志着"**在中国，为中国**"（China for China）战略的深化落地。

### 国产竞争格局变化

**行业结构性转变：** 2026环博会上，水质分析领域呈现"进口品牌大幅缩减、国产仪器百家争鸣"的格局。各家国产展商不论老牌还是新秀，向客户介绍时几乎都会说"我们可以对标哈希"。这印证了之前的判断：哈希正在成为国产厂商的**技术对标基准**，既是压力也是品牌护城河。

### 关税影响与本土化应对

哈希采取"**更彻底的本土化**"应对关税挑战，包括：增加国内研发比例、供应链本土化、与国内集成商合作等策略，确保在中国市场的供应稳定性和成本竞争力。
