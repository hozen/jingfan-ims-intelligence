# IMS IB增长战略研究：300→1000台实施方案

> **状态**: 启动
> **启动时间**: 2026-04-20

---

## 核心问题

**如何将iMS Install Base从300台增长到1000台？**

四个已知的增长路径：
1. **付费销售驱动** — 当前主力，200万目标对应约1000台IB，但转化率低
2. **试用转化机制** — 标准试用流程已建立，目标试用转正式订单
3. **渠道合作铺货（CP）** — 尚未启动
4. **存量仪表激活（白区）** — 50,000台存量中仅300台有iMS，空白巨大

> **核心瓶颈：路径①②在运转，路径③④几乎空白。仅靠软件销售1人的付费销售，1000台目标安全边际不足。**

---

## 关键约束条件

- iMS是部署在客户现场的工业软件，不能云端访问客户数据
- 仪表销售团队覆盖各大区，有最大的客户接触面
- 目前无专职IB执行人
- 目标从300台增长到1000台（增量700台）
- 200万软件Booking目标对应约1000台IB（但实际可能只有50万）

## iMS战略定位

### 核心洞察：定位决定决策链

| 定位 | 决策者 | 可行性 |
|------|--------|--------|
| **设备科视角：智能运维工具** | 设备科（自行决定） | ✅ 主攻方向 |
| **全场智能化平台** | IT + 信息部 + 副总 | ❌ 几乎死局 |

**设备科天然是IMS的买家：**
- 需求：仪表数据准确性、在线率、运维成本
- IMS从智能运维角度切入，解决设备科KPI
- 费用低（仪表价格的个位数%），设备科有预算
- **绕过IT/信息部，不触发复杂的跨部门决策链**

**行业背景：**
- "十五五"开局，监管从参数监测转向数据驱动的运营合规
- 国务院831号令要求合规记录自动化
- 客户采购决策从"设备科选型"上升到"运营层战略投入"（需避免）

## 四个研究问题

### Q1：工业软件/IIoT平台领域有哪些可借鉴的行业最佳实践？

重点方向：
- Rockwell PTC、Siemens、Schneider等工业软件巨头的IB管理机制
- 软件订阅模式下的IB扩张策略
- 工业IoT平台的渠道/合作伙伴拓展模式

### Q2：如何设计仪表销售团队与软件团队的协同激励机制？

重点方向：
- 仪表销售团队为什么没有动力推iMS（利益结构分析）
- 工业品直销+软件混合业务模式下的激励机制设计
- 线索确认机制（Lead Attribution）如何设计

### Q3：存量客户激活（白区转化）最有效的切入方式是什么？

重点方向：
- 50,000台存量中，哪些客户最有可能转化
- 激活的切入场景（年检/耗材采购/故障/升级）
- 低成本激活方式（不需要大规模销售拜访）

### Q4：渠道CP铺货的激励结构应如何设计？

重点方向：
- 工业仪表渠道商（CP）的利益诉求
- CP在项目中默认集成软件的机制
- 渠道激励 vs 直销激励的差异
