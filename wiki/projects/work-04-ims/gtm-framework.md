# GTM框架：采购决策链分析

## 1. 核心概念：Buying Center（采购中心）/ DMU（决策单元）

B2B工业品/设备采购中，决策不是一个人做出的，而是多个角色共同影响。

### DMU典型角色

| 角色 | 关注点 | 影响力 |
|------|--------|--------|
| **使用者（User）** | 产品是否好用、能否完成工作 | 提需求，但不一定有决策权 |
| **技术把关者（Technical Gatekeeper）** | 技术是否合规、兼容、安全 | 一票否决权 |
| **财务把关者（Financial Gatekeeper）** | 预算是否足够、价格是否合理 | 一票否决权 |
| **决策者（Decision Maker）** | 最终拍板 | 最终签字 |
| **Champion（内部倡导者）** | 内部推动者 | 关键盟友，帮助推进 |
| **Blocker（拦截者）** | 反对采购的人 | 可能来自竞争对手、或其他部门 |

> **IMS场景洞察**：设备科 = User + Decision Maker（在小额采购上）；IT/信息部 = Technical Gatekeeper；副总 = 最终决策者（当预算够大时）

---

## 2. 干系人利益分析工具

针对每个角色回答三个问题：
1. **他们想要什么？**（利益/KPI）
2. **他们担心什么？**（风险/顾虑）
3. **如何让他们支持你？**（价值主张）

### Hach IMS场景下的DMU分析

#### 设备科（User + Decision Maker，小额采购）
- **利益**：仪表在线率、数据准确性、运维成本降低、巡检效率提升
- **顾虑**：学习成本、系统是否稳定、与其他系统的兼容性
- **切入点**：IMS是设备科自己的工具，不是IT系统

#### IT/信息化部门（Technical Gatekeeper）
- **利益**：全场数据统一、安全合规、系统稳定性
- **顾虑**：IMS是否与现有系统冲突、谁来运维、数据安全
- **切入点**：提供API文档、技术白皮书，强调"不上IMS才危险"（数据孤岛风险）

#### 副总/厂长（Decision Maker）
- **利益**：全场智能化转型、成本控制、合规
- **顾虑**：投资回报率、政治风险（得罪IT部门）
- **切入点**：IMS是仪表资产管理的"轻量化"方案，不是ERP替代品

## 3. GTM落地：找到你的Champion

**Champion特征：**
- 在客户内部有决策影响力
- 强烈认同Hach/IMS的价值
- 愿意主动在内部推动

**如何培养Champion：**
1. 找到那个最先抱怨"巡检数据对不上"、"仪表台账混乱"的人
2. 给他们一个成功的Pilot案例
3. 让Champion自己内部讲IMS的价值，比外部推销有效10倍

---

## 4. 竞品场景：如何处理"竞品已签合同"的情况

当客户已有IT合同（Baidu/华为/其他）时：
- **不要正面进攻IT部门**——他们的地盘，赢不了
- **绕道设备科**：从设备科的实际痛点出发，让设备科主动提出IMS需求
- **让设备科去说服IT部门**：内部政治比外部推销更有效

## 5. GTM策略选择

### 策略A：设备科直销（小额、快速）
- 定位：IMS = 设备科智能运维工具
- 决策链短，设备科自己拍板
- 适合：新客户、巡检包续约、仪表采购时捆绑

### 策略B：内部Champion推动（大额、复杂）
- 定位：IMS = 仪表资产完整性管理方案
- 找到Champion → Champion内部推动 → IT合规 → 副总批准
- 适合：已有运维合同的客户、年度框架客户

### 策略C：竞品替换窗口
- 窗口：客户现有合同到期 / 系统出问题 / 领导换届
- 主动出击，不是等客户来找

## 6. Customer Journey（客户旅程）

```
认知(Awareness)
    ↓
考虑(Consideration)
    ↓
评估(Evaluation)
    ↓
决策(Decision)
    ↓
实施(Installation)
    ↓
采纳(Adoption)
    ↓
续约/复购(Renewal/Expansion)
```

### 各阶段的关键任务

| 阶段 | 关键问题 | 关键动作 |
|------|---------|---------|
| 认知 | 客户知道有这个问题吗？ | 内容营销、行业会议、触达 |
| 考虑 | 客户在比较方案吗？ | 差异化价值主张、案例背书 |
| 评估 | 客户在深入了解IMS吗？ | 技术文档、POC、Pilot |
| 决策 | 谁在拍板？ | 应对DMU、清除Blocker |
| 实施 | 怎么交付？ | 项目管理、培训、交接 |
| 采纳 | 客户真的在用吗？ | 成功激活、用户培训、反馈收集 |
| 续约 | 客户愿意续吗？ | 价值呈现、关系维护、Upsell机会 |
