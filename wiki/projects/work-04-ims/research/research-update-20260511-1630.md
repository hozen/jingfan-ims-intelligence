## 一、P0优先级验证：北疆电厂群实际接触情况

### 1.1 北疆电厂群构成

北疆电网覆盖的主力电厂群：

| 区域 | 代表电厂 | 机组规模 | 水处理场景 |
|------|---------|---------|-----------|
| 乌鲁木齐 | 华能乌热电、国电红二电 | 2×330MW+ | 循环水、排污水 |
| 昌吉 | 华电昌吉、国投准东 | 2×660MW+ | 循环水、脱硫废水 |
| 石河子 | 天富热电、天业自备 | 2×350MW+ | 循环水、化学水 |

### 1.2 P0激活逻辑验证

**为什么北疆是P0（最高优先级）？**

1. **化工园区密集**：乌鲁木齐-昌吉-石河子三角地带是新疆化工最密集区域，废水排放监管最严
2. **水资源最紧缺**：天山北坡水资源开发利用率已超40%红线，取水口监测需求强
3. **政策试点先行**：新疆环保厅的"831"减排行动计划通常先在北疆试点

**实际接触情况分析**：

基于前期软件销售拜访积累的客户信息：
- 已有接触的北疆电厂：3-5家（均为循环水场景）
- 尚未接触的北疆电厂：约15-20家
- **白区激活空间**：约80%的北疆电厂仍是白区

### 1.3 下一步接触策略

```
P0客户接触路径：
  1. 通过仪表销售团队获取电厂生技部联系方式
  2. 以"仪表数据联网"为切入点（非IMS直接推销）
  3. 捆绑现有 Hach 仪表更换需求 + IMS打包
  4. 目标：第一批试点（2026年Q3前）
```

## 二、脱硫废水零排放市场规模量化

### 2.1 政策背景

- **"十四五"水污染防治规划**：明确要求燃煤电厂脱硫废水"零排放"
- **新疆专项**：2024年起新疆环保厅对脱硫废水排放监管升级
- **全国现状**：全国约2000台燃煤机组，约60%已完成脱硫，零排放改造比例不足10%

### 2.2 市场规模估算

| 维度 | 数据 |
|------|------|
| 全国燃煤电厂数量 | ~2000台机组 |
| 已完成零排放改造 | ~200台（10%） |
| 待改造量 | ~1800台 |
| 单台改造平均成本 | 800-2000万元 |
| **潜在市场总规模** | **144-360亿元** |
| 其中IMS/监测系统占比 | 5-10%（7-36亿元） |

### 2.3 新疆市场专项

| 维度 | 数据 |
|------|------|
| 新疆燃煤电厂数量 | ~80台机组 |
| 已完成零排放改造 | <10台 |
| 待改造量 | >70台 |
| 新疆市场IMS/监测系统规模 | **0.5-2亿元** |

### 2.4 脱硫废水监测的IMS切入角度

脱硫废水零排放监测的核心参数：

| 参数 | 监测难点 | IMS适配度 |
|------|---------|----------|
| 重金属（砷、汞、铅） | 技术壁垒高，需专用仪器 | ⭐⭐⭐ |
| pH、浊度 | 常规参数 | ⭐⭐⭐⭐⭐ |
| 氟化物 | 特殊监管要求 | ⭐⭐⭐ |
| TDS/电导 | 连续在线 | ⭐⭐⭐⭐⭐ |

**IMS在脱硫废水的核心价值**：
- 边缘计算 + 低功耗 → 蒸发塘/盐卤结晶等无电力供应场景
- 数据链路 → 符合831号令的合规记录要求
- 多协议支持 → 重金属仪器数据集成

## 四、结论

### 核心发现

1. **P0优先级正确**：北疆电厂群80%仍是白区，激活空间巨大
2. **脱硫废水零排放市场**：全国144-360亿元市场，IMS可切入7-36亿元；新疆市场0.5-2亿元
3. **IMS差异化优势**：在无电力供应的蒸发塘/结晶盐场景，低功耗IMS是唯一可行方案

### Buffett评分

**当前评分**: 73/100（B+级）

**维持理由**：
- P0优先级地图得到验证
- 脱硫废水市场规模量化清晰
- 2026年HDC Demo可展示IMS在电力行业的标杆案例

**下次深化方向**：
- 接触P0电厂生技部，验证仪表更换需求
- 寻找新疆脱硫废水零排放项目的具体招标信息
