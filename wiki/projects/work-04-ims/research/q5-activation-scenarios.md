# 研究：IMS白区激活最佳场景分析

> 研究问题：仪表巡检、耗材采购、合同续约三大现有触点中，哪个是激活iMS最高效的场景？
> 背景：Hach已有仪表巡检机制；90%+存量仪表可直连iMS；50,000台存量中仅300台已激活

---

## 一、三个候选场景对比

| 维度 | 场景A：仪表巡检 | 场景B：耗材/备件采购 | 场景C：合同续约 |
|------|--------------|---------------------|----------------|
| **现有机制** | ✅ 有，正在运行 | ✅ 有，客户主动复购 | ✅ 有，Hach主动推动 |
| **接触客户谁** | 服务工程师/仪表销售 | 采购/运营 | 销售经理 |
| **客户决策意愿** | 低（被动接受） | 中（已有采购需求） | 高（主动谈判） |
| **单次触达规模** | 低（1-3台/次） | 中（批次采购） | 高（整厂/整批次） |
| **激活阻力** | 中（需顺带开口） | 低（自然延伸） | 低（续约捆绑） |
| **执行主体** | 现场服务工程师 | 内部销售支持 | 仪表销售经理 |
| **需要改变什么** | 给服务工程师一个"开口话术" | 采购流程嵌入 | 续约时加赠品 |

## 二、场景A：仪表巡检——最低成本入口，但执行最复杂

### 2.1 Hach巡检机制实际运作（推断）

> 注：以下为基于行业惯例的推断，具体流程需Hach内部确认

**谁做巡检：**
- Hach内部服务工程师（执行主体）
- 仪表销售可能陪同（大客户）

**巡检做什么：**
1. 现场读取仪表数据（校准状态、运行参数）
2. 记录到服务报告（纸质或单机系统）
3. 发现问题现场处理或记录待跟进
4. 与客户仪表负责人交代注意事项

**巡检频率（推断）：**
- 有SCS合同的客户：每季度或半年1次
- 无合同的客户：仅故障时上门

**现有问题（从用户反馈推断）：**
- 巡检结束后与客户的关系即终止——无持续连接
- 服务工程师没有推软件的KPI——无动力带出iMS
- 巡检报告客户留存率低——纸质/单机系统

### 2.2 为什么巡检是最佳"开口"场景

**符合"最低阻力激活"的原则：**
- 服务工程师已在客户现场（无额外交通成本）
- 客户已有Hach工程师在场（信任关系已建立）
- 巡检过程本身就是数据采集场景——自然过渡到"这台数据以后可以自动上传"
- 不需要客户做IT改造，不影响当前工作流程

**激活成本极低：**
```
现有巡检 + 加一个动作：
"这台仪表可以连上我们的IMS，以后您不用等我们来才知道数据，在办公室就能看到实时状态"
→ 巡检结束时顺带完成iMS激活配置（15-30分钟）
```

### 2.3 巡检场景的三个关键改造点

**改造1：服务工程师的KPI和话术**
- 问题：服务工程师没有推软件的动力（利益不归他）
- 解决方案：
  - 巡检中发现iMS机会→算服务工程师推荐奖（哪怕只有100-200元/台）
  - 提供标准话术："您这台仪表支持联网，我来帮您激活，以后手机就能看数据"

**改造2：巡检报告数字化**
- 问题：纸质报告没有持续连接
- 解决方案：
  - 巡检报告通过iMS系统提交→客户自动获得仪表健康仪表板访问权
  - 这本身就是iMS的价值演示（客户立刻感受到价值）

**改造3：巡检后的72小时跟进机制**
- 问题：巡检结束后客户关系即终止
- 解决方案：
  - 巡检完成后，服务工程师提交客户信息→iMS系统自动发送激活指引邮件/微信
  - 72小时内软件团队主动联系客户协助激活

### 2.4 巡检场景执行流程（推荐）

```
Step 1: 巡检出发前
- 服务工程师在移动端查看今日巡检客户列表
- 系统提示：该客户有多少台Hach仪表，其中哪些已激活iMS
- 工程师知晓：这是激活机会

Step 2: 巡检现场
- 完成正常巡检流程
- 发现支持iMS的仪表（系统已标注）
- 顺带说："您这台可以联网，我现在帮您开通，手机就能看实时数据"
- 若客户同意：现场完成基础激活配置（约15-20分钟）

Step 3: 巡检结束
- 服务工程师提交巡检报告（iMS系统）
- 系统自动发送：仪表健康报告 + iMS功能介绍
- 软件销售团队72小时跟进：确认激活状态，协助深度配置

Step 4: 激活完成
- 客户获得：实时仪表健康仪表板访问权
- Hach获得：与该客户的持续数字化连接
```

## 三、场景B：耗材/备件采购——自然延伸，激活阻力最低

### 3.1 为什么有效

**客户逻辑：**
- "我已经在买Hach的试剂/备件了"
- "加上iMS不过是多一个服务项目"
- "反正你们工程师要来换试剂，顺便帮我联网也行"

** Hach逻辑：**
- 耗材订单是客户接触Hach最频繁的场景
- 每次耗材采购是激活iMS的机会
- 激活成本：随耗材附送iMS激活码（边际成本极低）

### 3.2 具体操作方式

**方式1：买试剂包激活iMS**
- 客户订购Hach试剂包（如COD试剂、余氯试剂）
- 随货附送iMS激活卡（类似手机SIM卡）
- 激活卡上写："扫码绑定您的仪表，免费使用IMS 3个月"
- 3个月后自动转为正式订阅（客户可拒绝，但通常不会）

**方式2：耗材采购平台的软性推广**
- 在Hach试剂/备件在线商城的产品页，增加iMS推广位
- "本产品支持连入哈希靖帆IMS，点击了解"
- 采购时自然曝光iMS

### 3.3 局限性

- 激活率低：只有正在采购的客户才能触达
- 客户决策者（采购）而非使用者（运营）——采购可能不关心iMS
- 需要内部协调：耗材销售团队和软件销售团队的协同

## 四、场景C：合同续约——最高价值激活，但规模有限

### 4.1 适用对象

- 已有SCS（Service Contract）服务合同的客户
- 这是Hach最忠诚、付费意愿最高的客户群

### 4.2 操作方式

**方式1：续约赠品**
- 在SCS合同续约时，将"iMS基础版（3-5台仪表）免费升级"作为续约优惠
- 客户感知：续约价格不变，多了一项服务
- Hach感知：激活成本低（边际成本接近零），但获得了与忠诚客户的持续连接

**方式2：续约+扩容**
- 客户有10台仪表在服务合同中，想加5台新表
- 在新表上默认预装iMS→"您这15台现在都能在我们的IMS平台上统一管理"

### 4.3 关键优势

- 客户已有付费意愿和付费习惯（SCS合同证明）
- 续约是主动接触客户的节点（不用找理由）
- 对于已有多厂的水务集团，可在合同层面推动"集团级IMS部署"

### 4.4 局限性

- 规模有限：只有SCS客户能享受，渗透率本身低
- 续约周期长（通常1年1次），激活速度慢
- 需要销售经理主导，软件销售1人无法覆盖所有续约谈判

---

## 五、推荐：优先级排序

基于"执行阻力 × 激活规模 × 激活速度"三维评估：

| 优先级 | 场景 | 推荐理由 |
|--------|------|----------|
| **最高** | A：巡检 + 数字报告 | 最低阻力、最大规模、快速规模化 |
| **高** | C：SCS续约捆绑 | 高价值客户的精准激活 |
| **中** | B：耗材采购附送 | 持续曝光，但转化率低 |
| **低** | 单独软件销售（现状） | 规模有限，不能规模化 |

## 六、核心建议：改造"巡检"作为iMS规模化的主引擎

**逻辑：**

工业IoT软件的规模化路径不是"软件销售"（漏斗太窄），而是"设备绑定"（设备卖到哪，软件就连到哪）。

Hach每年卖10,000台新机，如果每台新机在交付时默认激活iMS：
- 第1年：10,000台新激活
- 第2年：20,000台累计
- 第3年：30,000台累计

这才是从300→1000→10000的现实路径，而不是靠1个软件销售去跑客户。

**具体建议（新机交付即激活）：**

```
新机交付流程改造：
1. 仪表销售签单 → 系统自动触发iMS激活任务
2. 现场交付时，工程师完成仪表安装 → 同时完成iMS联网配置
3. 客户获得：仪表安装 + iMS账号开通（一次性动作）
4. 后续：每年续费通知（低接触维护）
```

**关键：把iMS激活从"软件销售事件"变成"仪表交付的标准步骤"**
