## 四、MMS数据质量保障：报警数据集成架构

### 4.1 数据流设计

```
IMS现场网关（MQTT/TCP）
    │
    │ ─── [设备状态标志] ─── MMS聚合层
    │        │                    │
    │        │                    ├── 报警去重（5min窗口）
    │        │                    ├── 频率过滤（>10次/小时→通信故障）
    │        │                    ├── 瞬时报警标注
    │        │                    └── 有效报警 → 报表系统
    │        │
    │ ─── [原始测量数据] ── MMS时序数据库
    │        │
    │        └── 数据清洗（校准、异常值剔除）
    │
    ▼
云端/本地MMS平台
```

### 4.2 关键集成参数

| 参数 | 推荐值 | 说明 |
|------|-------|------|
| MQTT QoS | 2 | 确保报警送达 |
| 报警去重窗口 | 5min | 同一设备同类型只保留首条 |
| 频率过滤阈值 | 10次/小时 | 超过判定为通信故障 |
| 瞬时报警阈值 | 5min | 自动恢复且<5min标记为瞬时 |
| 状态上报周期 | 30s | 设备状态变化立即上报 |
