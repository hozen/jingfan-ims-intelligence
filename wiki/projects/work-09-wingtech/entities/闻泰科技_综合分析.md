# 闻泰科技 经营状况综合分析

**分析日期：** 2026年4月26日
**数据来源：** 上交所公告（东方财富API抓取）、现场调研（2026年4月25日）

---

## 一、现场调研核心结论（维持）

**规模收缩型正常经营，无倒闭风险。**

闻天下广场入住率<1/3、裙楼毛坯空置，与财务"规模收缩"吻合，但技术员工正常下班（有出差/商务），公司仍在正常运营。

---

## 二、重大风险事件时间线（2025Q4-2026年4月）

### 事件1：美国实体清单（2024年12月，已在2024年报确认）
- 2024年12月2日，BIS将闻泰及其部分子公司列入**美国"实体清单"**
- 影响：产品集成业务（ODM）的采购和销售**逐步受限**，未来业务量下降
- 现场印证：ODM业务-33%，营收736亿但净亏28.3亿

### 事件2：安世半导体控制权危机（2025年9-10月）⚠️ 最核心风险
| 时间 | 事件 |
|------|------|
| 2025/9/30 | 荷兰经济事务与气候政策部对安世下达**部长令（Order）**，要求全球30个主体对资产、IP、业务、人员不得做任何调整，有效期1年 |
| 2025/10/1 | 安世荷兰高管（Ruben Lichtenberg CLO + CFO + COO）向阿姆斯特丹企业法庭提交紧急请求 |
| 2025/10/7 | 企业法庭裁决：①暂停张学政（实控人）执行董事/非执行董事职务；②任命外籍独立非执行董事（拥有决定性投票权）；③安世股份托管给独立第三方 |
| 2025/10/13 | 闻泰股票/转债复牌 |

**核心影响：** 裕成控股（闻泰全资子公司）失去安世半导体控股99%股份的股东权利（治理权/投票权），**控制权暂时受限**。闻泰的**经济收益权不受影响**，但控制权受损。

### 事件3：重大资产出售（2025年3月启动，2026年持续）
- **出售对象：** 转让给立讯精密（工业股份/立讯通讯）：5家子公司100%股权 + 3家子公司业务资产包
- **目的：** 收缩产品集成（ODM）业务，保留安世半导体
- **状态：** 除**印度业务资产包**尚在新加坡国际仲裁中心（SIAC）仲裁外，其余已完成交割
- **仲裁争议：** 印度资产包协议履行争议，仲裁尚未开庭

### 事件4：2025年业绩大亏（2026年1月预告）
- 预计2025年归母净利润：**-90亿至-135亿元**（亏损）
- 扣非净利润：**-2亿至-3亿元**（亏损）
- 主因：安世控制权受限 → 确认大量投资损失 + 资产减值损失

### 事件5：信用评级下调（2026年2月）
| 调整前 | 调整后 |
|--------|--------|
| 主体信用：AA-（稳定） | 主体信用：**A（负面展望）** |
| 债项信用：AA- | 债项信用：**A** |

### 事件6：审计师变更（2026年1月）
- 原审计师：众华会计师事务所（2024年报 → **标准无保留意见**）
- 过渡：普华永道中天（2025年10月被聘任）
- 最新：2026年1月改聘**容诚会计师事务所**（负责2025年报）
- 审计费用：480万元（较2024年+30万）

### 事件7：转债转股价格下修（2026年4月）
- 修正前：43.60元/股
- 修正后：**32.66元/股**（2026年4月10日生效）
- 触发条件：2026年2月2日至3月2日，任意连续30个交易日中有15个交易日收盘价低于43.60×85%=37.06元

## 五、可转债（闻泰转债 110081）分析

### 基本条款
| 项目 | 内容 |
|------|------|
| 发行规模 | 86亿元 |
| 发行日期 | 2021年7月28日 |
| 期限 | 6年 |
| 评级 | A（负面展望） |
| 当前转股价 | 32.66元/股（2026年4月10日生效） |

### 转债风险
1. **正股价格压力**：转股价下修至32.66元，若正股继续下跌，转债债底保护弱
2. **信用风险**：评级下调至A，债项评级A
3. **赎回条款**：若正股连续30个交易日中有15日≥转股价×130%（=42.46元），可能触发提前赎回
4. **回售条款**：若正股跌跌不休，持有人可回售给公司

### 转债持有建议
- **无需恐慌抛售**：公司正常经营（规模收缩型），破产风险低
- **关注2025年报审计意见**：若为非标，转债价格将承压
- **32.66元转股价**是博弈焦点：正股若能在32.66元以上企稳，转债有债底保护

## 七、核心结论

### 规模收缩型经营 ✅ 无即时倒闭风险

闻泰科技处于"规模收缩型正常经营"：
- 仍在正常运营（有商务出差、员工有序下班）
- 总部大楼"低入住率+毛坯空置"是业务收缩的物理体现
- 安世半导体控制权问题是**最大风险变量**，但不是"倒闭风险"

### 真正的风险是"持续失血"

| 业务 | 趋势 | 核心问题 |
|------|------|---------|
| ODM（产品集成） | -33%，持续下滑 | 被美国实体清单限制，已开始资产出售 |
| 半导体（安世） | +11%，但控制权受限 | 荷兰法律纠纷，审计师可能非标 |
| 整体 | 2025年巨亏90-135亿 | 主要是投资损失+减值，非经营失血 |

### 持仓建议

1. **转债**：不恐慌抛售，但需密切关注2025年报（预计4月底披露）——若审计意见为非标，应考虑减仓
2. **监测指标**：
   - 2025年年报披露时间（4月底截止）
   - 审计意见类型（关键！）
   - 安世半导体控制权纠纷进展
   - 印度业务仲裁结果
3. **最大尾部风险**：若2025年报被出具"无法表示意见"，将直接触发退市风险
