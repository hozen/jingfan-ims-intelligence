# 中国铁路货运经济观察 (work-02)

## 项目概述

借鉴 Berkshire Hathaway 通过 BNSF 铁路运量观察美国实体经济的方法，建立一套通过中国铁路货运数据反映中国实体经济、出口经济、以及中国-欧洲商业环境的研究框架。

**最终目标**: 为 F&I 投资体系持仓决策提供"无法造假的实体经济交叉验证信号"。

## 核心逻辑

铁路货运数据三大独特价值：
1. **物理流动信号**: 车皮里装的水泥就是水泥，不存在金融数据的口径调整空间
2. **领先指标特性**: 大宗商品和工业品运输通常领先 GDP 数据 1-3 个月
3. **结构信息丰富**: 不是单一数字，而是"什么类目运了多少"的多维向量

## 研究框架

### 纵向页面（时间序列）
追踪单一指标的演化
- "大秦线 2024-2027 运量月度数据"
- "中欧班列去程/回程比例季度演化"

### 横向页面（交叉映射）
连接铁路数据与持仓决策
- "煤炭物流信号 → 神华/盘江/新集 持仓判断"
- "集装箱运量 → 美的/申洲 出口景气"

### 专题页面（主题深挖）
- "2026 中欧班列结构性变化（俄乌战争后）"
- "大秦线运量为什么是中国煤炭风向标"
- "Berkshire BNSF 方法论在中国的本土化适配"

## 数据来源

- 国家铁路集团有限公司月度运营数据
- 大秦铁路(601006)/广深铁路(601333)上市公司公告
- 中国煤炭运销协会环渤海煤炭运量数据
- 中欧班列各平台公司运营数据
- 海关总署铁路口岸数据
- BNSF/UP/CSX 月度运量（中美对照）

## 关键原则

- 所有数据必须可溯源
- 不允许编造数据；数据缺失时明确标注"数据待补"
- 持仓决策建议必须标注"agent 观察"vs"决策建议"
- 当不确定时，默认保守：观察 > 建议
