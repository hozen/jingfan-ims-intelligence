## 零、核心结论（已验证）

> **五指耙水厂（2026-03投运）已证明：网关方案是 Hach 接入鸿蒙生态的唯一现实路径。**

- 深圳水务默认的接入方式就是**网关方案**：仪表只需输出标准 MODBUS 数据，无需 HarmonyOS Connect 认证
- 10余家设备厂商参与五指耙水厂建设，从招标到投运仅数月——不可能每家都单独做了认证
- **对 Hach 的意义**：加配鸿蒙边缘网关（如 IPC3528），仪表零改动，最快可用的接入路径

## 四、深圳水务已落地的技术架构

### 实际运行案例：五指耙水厂（2026-03投运）

```
Hach仪表（MODBUS RTU/TCP）
    → 鸿蒙PLC控制系统
    → B-LINK闪链（近场安全连接）
    → 水鸿WaterHMOS系统（统一调度）
    → 深水云脑2.0（AI分析）
```

### 关键系统组件

| 组件 | 名称 | 说明 |
|------|------|------|
| 操作系统 | 水鸿WaterHMOS | 深圳水务定制版OpenHarmony |
| 网关 | IPC3528鸿蒙边缘计算网关 | 瑞芯微RK3568，MODBUS驱动 |
| 近场连接 | B-LINK闪链 | 碰一碰建立安全连接，查看参数/历史曲线/远程控制 |
| 云平台 | 华为云IoT | 设备接入和数据汇聚 |
| AI平台 | 深水云脑2.0 | AI辅助决策 |

## 五、Hach接入鸿蒙的最优技术路径

### 结论：网关方案（不改仪表，不做HarmonyOS Connect认证）

```
Hach仪表（已有标准MODBUS RTU/TCP）
    → 加配鸿蒙边缘网关（如IPC3528）
    → 网关运行OpenHarmony + MODBUS驱动
    → 接入华为云IoT平台
    → 汇入水鸿WaterHMOS系统
```

### 为什么走网关而非认证

| 对比项 | 网关方案 | HarmonyOS Connect认证 |
|--------|----------|----------------------|
| 仪表改动 | 无 | 需要加通信模块 |
| 认证周期 | 无 | 3-6个月 |
| 成本 | 低（外置网关） | 高（重新设计硬件） |
| 适用场景 | 工业仪表 | 消费/智能硬件 |
| 对Hach的意义 | 最快可用 | 不适用 |

### ⚠️ 关键验证：五指耙水厂已证明网关方案可行
- 10余家设备厂商参与，从招标到投运仅数月
- 这10余家不可能每家都单独做了HarmonyOS Connect认证
- **结论：深圳水务默认的接入方式就是网关方案，仪表只需输出标准MODBUS数据**
- 深圳水务作为系统集成方（B-LINK近场连接+WaterHMOS平台），对仪表厂而言网关方案是唯一现实路径

### 具体行动步骤

1. **寻找集成商合作伙伴**：尚易科技（已跑通OpenHarmony网关+水务接入）
2. **确定网关型号**：IPC3528（RK3568，已在水务场景验证）
3. **测试MODBUS协议对接**：Hach仪表已有标准MODBUS输出，验证数据采集
4. **与深圳水务科技接触**：通过马丹红团队了解深圳水务实际需求
5. **商务对接**：深圳环水集团/水务局 → 成为"鸿蒙生态合作伙伴"

## 六、吉林光大深度核实结论

### 公司基本情况（已确认）
- **全称**：吉林市光大分析技术有限责任公司
- **成立**：1997年，注册资本2857万元
- **地址**：吉林市
- **定位**：国产化水质在线监测仪表企业，国家环保制造业规范条件入选企业
- **产品线**：水质在线监测系统、饮用水多参数在线监测仪（主打二次供水）、水质在线监测仪表
- **应用案例**：上海迪士尼、三峡水文局船载移动站、上海松江东部自来水厂、吉林市四水厂等
- **研发能力**：自建市级企业研发中心，50+研发人员，设有国家博士后光机电科研工作分站

### 鸿蒙认证核实结果：❌ 无公开证据
- 官网所有页面无任何"鸿蒙"、"HarmonyOS"、"华为"关键词
- 公司新闻（2020-2025）无任何鸿蒙/华为相关动态
- 产品页面未标注任何认证信息
- 搜索"光大分析 + 鸿蒙/认证/HarmonyOS"全网无匹配结果

### ⚠️ 重要区分：二次供水 vs 工业水厂
- **光大分析主打产品"饮用水多参数在线监测仪"**：针对**二次供水**（民用二次供水泵房）和农村饮水安全规模化水厂
- **Hach产品定位**：市政水厂、工业过程水、污染源监测——**不在同一赛道直接竞争**
- 二次供水是**民用 residential**场景，Hach是**工业 industrial**场景
- 如果销售/经销商听到的"吉林光大通过认证"是指二次供水场景，则与Hach核心业务无关

### 判断
"吉林光大通过鸿蒙认证"的传言很可能是：
1. **误传**：将"光大分析做了二次供水 + 听说有鸿蒙认证要求"混淆
2. **测试阶段**：正在与华为/深圳水务接触，但尚未正式认证
3. **内部认证**：认证不对外公开，只在特定生态伙伴名单中

**需要直接询问销售：消息来源是谁？是光大自己宣传的，还是第三方渠道听说的？**
