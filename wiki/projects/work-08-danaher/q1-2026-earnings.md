## 三大事业群表现

### 1. 生物工艺（Bioprocessing）事业群
| 指标 | 数据 |
|------|------|
| 营收 | **17.97亿美元**，同比+11.5% |
| 环比 | -11.6%（季节性，正常） |
| 耗材收入 | **中国药厂需求强劲**，是主要驱动力 |
| 设备收入 | 下滑 |
| 设备订单 | **订单增长未在10-Q中披露**；10-Q原文仅提及"设备收入下滑"；RPO FY24→25增长21%或为来源，但30%无法核实 |
| 蛋白研究仪器 | 因学术客户资金限制下滑 |

### 2. 生命科学（Life Sciences）事业群
| 指标 | 数据 |
|------|------|
| 营收 | **17.37亿美元**，同比+3.5% |
| 仪器业务 | 低个位数下降 |
| 原因 | 北美学术客户需求疲软，NIH拨款延迟 |
| 大型制药/生物制药 | 投资逐步改善 |
| Abcam | 实现增长 |
| DBS成本优化 | 带来显著利润率提升 |

### 3. 诊断（Diagnostics）事业群
| 指标 | 数据 |
|------|------|
| 营收 | **24.17亿美元**，同比-1.5% |
| 临床诊断（不含中国） | 低个位数增长 |
| 中国诊断业务 | **高个位数下降**（VBP+医保政策影响，符合预期） |
| Cepheid分子诊断 | **呼吸道检测收入同比下降约25%**（感染率低） |
| 非呼吸道核心检测 | 中双位数增长，性健康+院内感染检测增长20% |

## 管理层全年指引与信心点

### 乐观看点
1. **中国增长进一步加速**
2. **生物工艺耗材增长加速，设备订单转化加快**（确定性事件）
3. **呼吸道业务Q4恢复至约18亿美元"新常态"**
4. **生命科学终端市场进一步改善**（尤其美国，但NIH不确定性仍存）
5. **收购Masimo与Radiometer实现业务协同**

### 管理层回应市场担忧
| 问题 | 回应 |
|------|------|
| 中东战事对供应链 | 不直接依赖中东，石油波动尚未产生实质影响 |
| AI对客户支出和公司业务 | 短期利好自动化/分析仪器/试剂；长期增加商业化药物数量，利好生物工艺和伴随诊断；丹纳赫正在将AI与DBS融合提升效率 |

## 文章核心观点

- Q1营收同比增长3.5%，但核心营收仅增0.5%，低于低个位数增长目标
- 诊断事业群未完成KPI：原本预计下滑低个位数（1-2个点），实际下滑4%
- 全年指引无大变化，整体**中规中矩**，谨慎乐观
- 中国业务：诊断板块受政策影响，但生物工艺耗材需求强劲
- AI是制药/生物技术行业的**增长加速器**，丹纳赫在融合AI与DBS

---

## 对Hach的启示

- 中国诊断业务因VBP承压，但生物工艺（和水质监测相关）耗材需求旺盛
- AI与DBS融合是丹纳赫内部效率提升方向，可关注Hach是否跟进
- RPO FY2024→2025增长21%是客观数据，设备订单活跃度确实在提升，但"30%"数字无法在SEC文件中核实；设备订单增长对Hach在线监测业务是潜在利好，但收入确认会滞后（参考RPO结构：53%跨年度确认）
- 收购整合（Masimo/Radiometer）是丹纳赫惯用成长手段，关注Hach后续动作
