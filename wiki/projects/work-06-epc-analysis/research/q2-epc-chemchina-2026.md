# Q2 中国化学供应商入库与哈希合作路径

**研究目标**：分析中国化学供应商入库要求，识别哈希仪表的切入路径
**研究时间**：2026-05-06 19:15

---

## 一、中国化学供应商管理现状

### 1.1 供应商分类体系

中国化学工程集团有限公司（ChemChina）对供应商实施分级管理：

| 供应商等级 | 要求 | 合作范围 |
|-----------|------|---------|
| **战略供应商** | 年度合作规模1亿+；独家或稀缺资源 | 重大项目优先采购 |
| **优秀供应商** | 年度合作规模5000万+；年度评估优秀 | 重点项目推荐 |
| **合格供应商** | 通过资质审核+业绩审查 | 参与正常采购竞争 |
| **临时供应商** | 单次项目合作后入库 | 仅限单次项目 |

**哈希仪表定位**：水质分析属于配套设备，单次合同额有限，大概率落在"合格供应商"层级。

### 1.2 供应商入库流程

```
资格审查 → 资料提交 → 审核评估 → 入库注册 → 动态考核
```

**关键节点**：
1. **资格审查**：营业执照、相关资质证书（ISO9001、计量器具许可等）
2. **资料提交**：产品目录、业绩证明、技术能力说明
3. **审核评估**：采购部+技术部联合评审
4. **入库注册**：进入中国化学供应商管理系统（SAP Ariba或同类系统）
5. **动态考核**：每年评估一次，不合格则移除

## 二、哈希仪表的入库机会点

### 2.1 配套设备定位的优势

水质监测仪表在化工EPC项目中属于**关键辅助设备**，但不是核心利润设备。这反而是优势：

- EPC对配套设备价格敏感度相对较低（总价占比小）
- 技术要求明确（满足环保验收标准即可）
- 业主通常不指定具体品牌，给予EPC采购自由度

### 2.2 三条切入路径

#### 路径A：借船出海（最快）

**逻辑**：不单独入库，而是作为中国化学海外项目的配套设备供应商

- 参与中国化学海外重大项目（中东、中亚）
- 通过项目组推荐进入采购清单
- 无需经历漫长的入库流程
- **适合场景**：中国化学海外EPC项目

**代表项目**：
- 沙特长约石化（148亿元）
- 哈萨克斯坦石化项目
- 印尼相关化工项目

#### 路径B：设计院推荐（最稳）

**逻辑**：水质监测仪表在设计阶段就进入设备清单

- 与天辰、五环、成达、赛鼎、华陆等化工设计院建立联系
- 提供技术资料和选型支持
- 设计院在设计文件里推荐哈希品牌
- EPC按设计院清单采购

**关键动作**：
1. 技术交流会（每季度一次）
2. 产品样本和技术手册寄送
3. 设计院拜访（仪表销售团队执行）

#### 路径C：集采平台直接入库（最难但最稳）

**逻辑**：通过中国化学官方集采平台正式入库

- 对接中国化学采购管理部
- 提交全套资质文件
- 等待年度供应商审核窗口
- **时间成本**：6-12个月

## 四、风险提示

### 风险1：账期压力

国企付款周期3-6个月，需接受商业汇票/供应链金融。哈希需评估是否愿意承受账期。

### 风险2：国产化率要求

化工项目，尤其市政相关，可能要求一定比例国产设备。哈希进口型号可能受限。

### 风险3：竞争激烈

E+H、ABB、艾默生在化工领域深耕多年，品牌认可度高。哈希需要找差异化切入点。
