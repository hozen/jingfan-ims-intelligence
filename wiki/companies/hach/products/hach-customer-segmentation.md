## 二、客户分类：两大类 vs 四小类

### 2.1 两大类（按采购/决策模式）

| 维度 | 市政客户 | 工业客户 |
|------|----------|----------|
| **典型主体** | 水务集团、自来水公司、排水管理处、市政污水厂 | 电力公司、石化厂、钢铁厂、电子厂、食品厂 |
| **采购模式** | 政府招标/集采 | 商务谈判/项目制 |
| **决策链** | 设备科→采购部→领导 | 工程部/技术部→采购 |
| **付费节奏** | 按合同年度服务费 | 按项目一次性 |
| **合规压力** | 强（政府监管） | 中等（自身EHS） |
| **服务合同** | 常见，有年度服务预算 | 不常见，按需服务 |

### 2.2 四小类（按服务模式和产品线交叉）

| 类别 | 代表客户 | Hach产品重心 | iMS适配度 |
|------|----------|-------------|-----------|
| **A类：市政水务（自来水）** | 深圳水务、北控水务、威立雅客户 | 余氯/浊度/氨氮/COD、SC控制器 | ★★★★★ 最高 |
| **B类：市政污水/排水** | 市政排水公司、工业园污水厂 | 总磷/总氮/VFA/硫化物/COD | ★★★★ 高 |
| **C类：大型工业（电力/石化/钢铁）** | 五大电力、中石油/石化、宝武 | 硅表/钠表/硬度/COD/TOC、重金属 | ★★★ 中 |
| **D类：中小型工业（食品/电子/制药）** | 食品厂、电子厂、药厂 | TOC/色度/溶解氧/多参数 | ★★ 低 |

## 三、iMS与客户分类的匹配分析

### 3.1 各细分类别的iMS核心价值锚点

**A类：市政水务（自来水）—— iMS渗透首选**

| 维度 | 分析 |
|------|------|
| **核心痛点** | 水厂多、仪表散（一个水务集团管10+水厂）、人工巡检成本高、合规记录繁琐（831号令） |
| **iMS价值锚点** | 集中监控减少巡检人工；合规报告自动生成；预测性维护减少突发故障 |
| **决策者** | 水务集团信息部/生产部副总 → 对降本和合规报告感兴趣 |
| **执行者** | 水厂仪表负责人 → 对减少故障报警次数感兴趣 |
| **购买障碍** | 预算审批流程长；IT部门对本地部署有安全顾虑 |
| **服务合同现状** | 较常见，有年度服务费预算 |

**B类：市政污水/排水—— 政策驱动的高潜力市场**

| 维度 | 分析 |
|------|------|
| **核心痛点** | 污水厂进水分水质波动大、COD/总磷/总氮频繁超标罚款、运维人员短缺 |
| **iMS价值锚点** | 实时预警+快速定位原因；减少超标罚款；预测性维护 |
| **政策触发点** | 831号令覆盖排水行业；"十五五"污水提标改造 |
| **特殊优势** | Hach在市政污水领域产品线全（NP5800/NT6800/VFA/硫化物） |

**C类：大型工业—— 产品深度绑定，但销售周期长**

| 维度 | 分析 |
|------|------|
| **核心痛点** | 电力/石化厂对仪表精度要求极高；故障停机损失大；仪表工程师编制精简 |
| **iMS价值锚点** | 预测性维护减少非计划停机；专家知识库辅助故障诊断 |
| **决策链** | 工程部→生技部→采购→领导，决策链最长 |
| **竞争态势** | 施耐德/ABB/西门子有本土自建平台；iMS是原厂工具，壁垒在Hach仪表排他性 |
| **服务合同** | 通常有长期服务合同，但合同通常不覆盖软件 |

**D类：中小型工业—— 标准化产品的标准化软件**

| 维度 | 分析 |
|------|------|
| **核心痛点** | 预算有限；无专职仪表工程师；买仪表后无人管 |
| **iMS价值锚点** | "买仪表不用操心"的托管式服务；远程技术支持减少现场服务成本 |
| **标准化可能** | D类客户最适合SaaS化的iMS基础版 |
| **激活路径** | 随仪表采购附带iMS激活码；通过经销商触达 |

## 四、iMS渗透率分布推测（待内部数据验证）

> 以下为逻辑推断，非实际数据，需Hach内部数据验证

| 客户类别 | 占存量50,000台比例（推测） | 已激活iMS比例（推测） | 渗透率（推测） |
|----------|--------------------------|---------------------|--------------|
| A类：市政水务 | ~30%（约15,000台） | ~60%（约180台） | ~1.2% |
| B类：市政污水 | ~20%（约10,000台） | ~20%（约60台） | ~0.6% |
| C类：大型工业 | ~35%（约17,500台） | ~15%（约45台） | ~0.26% |

## 五、仪表服务合同（SCS）与iMS的协同关系

> 数据来源：Hach官网产品页面（https://www.hach.com.cn）提及"服务与支持"模块

Hach服务合同（SCS, Service Contract）通常包含：
- 年度计量校准
- 现场巡检
- 故障响应（24小时）
- 备件更换（含原厂配件）

**iMS与SCS的协同机会：**
- SCS客户已付年度服务费，是Hach最"忠诚"的客户群
- 巡检工程师每次拜访是iMS激活的天然开口——"您的这台仪表现在可以接入iMS，以后在家就能看数据"
- 服务合同续约时将iMS基础版作为"续约赠品"是低成本激活路径

## 六、仪表巡检机制与iMS入口分析

### 6.1 仪表巡检做什么（来自官网推断）

来源：Hach官网"服务支持"模块

Hach现场服务包括：
- 计量校准（年度强制）
- 现场巡检（定期）
- 故障诊断与维修
- 备件更换

**每次巡检的服务流程（推断）：**
1. 工程师到达现场
2. 登录仪器记录校准数据
3. 检查仪表运行状态
4. 发现问题现场处理或记录
5. 填写服务报告

### 6.2 巡检场景转化为iMS入口的关键机会

**现有机制存在的问题：**
- 巡检报告是纸质或单机版 → 客户看不到实时数据
- 巡检结束后关系即终止 → 无持续连接
- 服务工程师没有推软件的KPI → 无动力带出iMS

**改造方案：**
在每次巡检服务中，服务工程师（或仪表销售陪同）做以下一件事：

> "帮您把这台仪表连上iMS，以后不用每次都来现场看数据，手机上就能看到仪表健康状态"

**操作方式（低成本）：**
- 巡检时带上iMS激活卡片（类似手机SIM卡激活流程）
- 扫描二维码→仪表序列号绑定→15分钟完成配置
- 不需要IT部门介入（本地部署，局域网即可）

## 七、iMS白区客户画像：哪些最应该优先激活

### 优先激活客户特征（easy win标准）：
1. **已有SCS服务合同**（Hach最忠诚客户，最容易接受追加服务）
2. **多台Hach仪表**（单台激活价值高，软件边际成本低）
3. **监管合规压力大**（A类/B类市政客户，831号令驱动）
4. **无专职仪表工程师**（运维人员精简，iMS替代人工价值大）
5. **曾反映过仪表故障/报警问题**（已有痛点，解决方案更易售出）

### 不优先客户特征：
1. **单台仪表采购**（激活价值低，软件分摊成本高）
2. **已有竞品SCADA系统**（iMS是替代方案，销售阻力大）
3. **C类大型工业**（决策链太长，软件销售1人无法覆盖）

## 八、iMS竞争定位：vs 客户自建SCADA

| 维度 | 客户自建SCADA | Hach iMS |
|------|--------------|----------|
| 仪表兼容性 | 多品牌混接 | 仅Hach仪表 |
| 仪表专家知识库 | 无 | 有（内嵌故障诊断） |
| 原厂服务 | 无 | 有（专家在线服务） |
| 部署成本 | 高（自建服务器+IT团队） | 低（私有化部署，Hach实施） |
| 适合客户 | 有IT团队的大型客户 | 无IT团队的中小型客户 |

**iMS的核心差异化**：不是通用的SCADA，而是**Hach仪表专用的智能运维平台**——仪表故障了，iMS知道原因（原厂知识库）；SCADA只知道报警，不知道怎么处理。
