### pptxgenjs陷阱：drawCard的h参数
drawCard函数参数`h`在text元素回调中超出作用域，会报`h is not defined`。
**解法**：必须用常量`LEFT_W`（0.72）代替，不能依赖参数传递。
```javascript
// 错误
function drawCard(slide, x, y, w, h, ...) {
  slide.addText("...", {
    y: y + h - 0.1  // h is not defined in this scope!
  });
}
// 正确
function drawCard(slide, x, y, w, h, ...) {
  slide.addText("...", {
    y: y + LEFT_W - 0.1  // use constant 0.72 instead of h
  });
}
```

### Slide B badge重叠问题（多次踩坑）
**根因**：badge放右上角（和公司名同一行），但公司名+展位号+产品描述三行内容实际占用高度超出设计行高，导致重叠。

**解法**：改为单列全宽卡片布局，每家公司独占一行，badge左侧放置。
- Badge右端x必须 < 页面宽度（10"），badge在x=9.04超出边界
- 单列全宽：LEFT_W=0.72"，CONTENT_W=8.13"，badge右端x=9.73"（页内）
- 各行y坐标精确分配：1.22 / 1.94 / 2.66 / 3.38 / 4.10 / 4.70 / 5.30

### PPT验证命令（zipfile+XML）
```bash
python3 -c "
import zipfile, re
with zipfile.ZipFile('output.pptx') as z:
    slides = sorted([n for n in z.namelist() if n.startswith('ppt/slides/slide') and n.endswith('.xml')], 
                    key=lambda x: int(re.search(r'slide(\d+)', x).group(1)))
    for i, s in enumerate(slides, 1):
        content = z.read(s).decode('utf-8', errors='replace')
        texts = re.findall(r'<a:t>([^<]+)</a:t>', content)
        print(f'Slide {i}: {texts[:5]}')
"
```
