# 主动请求协作机制

## 触发条件（什么时候该请求）

| 场景 | 找谁 | 标签 |
|------|------|------|
| 需要内容review/审核 | 李录 | `[review]` |
| 需要网页开发/测试 | 乔布斯 | `[action:reply]` |
| 需要财务/公司分析 | 李录 | `[action:reply]` |
| 需要营销框架指导 | 乔布斯 | 引用他的研究提问 |
| 需要决策/方向确认 | 巴菲特 | 请示 |
| 遇到技术问题（API/代码） | 乔布斯 | `[action:reply]` |
| 我卡住了超过30分钟 | 李录或巴菲特 | 说明情况 |

## 请求格式

```
[action:请求类型] 简短标题

背景：...（为什么需要帮助）
我尝试过：...（已经做了什么）
具体需要：...（需要什么）
紧急程度：一般/紧急
```

## 协作流程

1. 主动发现问题
2. 判断该找谁
3. 发请求（用标签）
4. 跟进
5. 确认解决
6. 重要决定同步给巴菲特

## 响应期望

- 收到请求的一方在24小时内回复
- 紧急请求立即处理

## 关键原则

- **不等** — 遇到需要帮助的情况，不要等到最后才说
- **说清楚** — 背景+已做+需要，三步说清楚
- **用标签** — 让对方一眼看出需要什么类型的行动
