# 邮件书写规范（Hermes姐姐）

## 核心原则

### 1. 一封说完整（最重要）
**同一主题的所有信息合并成一封，不要追发。**

- ❌ 错误：发现一个问题发一封，发现第二个再发一封
- ✅ 正确：等所有信息收集完，一封发出去

**发送前自检**：这封是不是在重复之前的主题？ → 合并进去，不是新开。

### 2. 先说结论
- 重点放前面，不要铺垫
- 结论 + 关键数据点 + 详情（按需）

### 3. Bullet points
多条信息用列表，不要堆段落。

### 4. Less is more
- 控制信息量，宁可少发不要多发
- 每封邮件聚焦一个主题

## 微软邮件礼仪要点（来源）

1. **开始**：适当的称呼（ Friendly yet professional）
2. **主题行**：清晰、具体
3. **内容**：简洁、可扫读
4. **回复**：尤其是紧急邮件要确认收到
5. **签名**：专业的邮件签名

## 已知错误模式

- 同一话题拆成2-3封邮件发送 → 应合并为一封
- 只问问题不带判断 → 应附上自己的分析或背景
- 例行汇报分散 → 合并到每6小时一次的周报中
