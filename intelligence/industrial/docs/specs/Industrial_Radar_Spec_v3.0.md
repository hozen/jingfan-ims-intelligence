# 1. 重新确认 Radar 的核心目的

iMS Industrial Radar 的核心目的不是：

> 比销售早几天看到招标公告。

也不是：

> 搜索即将开标的水处理项目。

更不是：

> 找到招标 → 看里面有没有仪表 → 判断 Hach 能不能投。

这些属于：

**Tender / Procurement Monitoring**

它们可以作为补充信息存在，但不是 Radar 的核心价值。

---

# 2. Radar 真正要回答的问题

Radar 应该帮助 Hach：

> **在客户需求已经出现、但解决方案和技术规格尚未冻结之前发现机会。**

理想时间轴：

**客户问题 / Trigger**

↓

**项目规划 / 技改意向 / 扩产 / 合规压力 / 运维痛点**

↓

**立项 / 可研 / 环评 / 资金安排**

↓

**方案设计**

↓

**设计院 / EPC 介入**

↓

**技术规格形成**

↓

**招标**

↓

**中标 / 采购**

Radar 最应该发现的是：

> **前半段。**

尤其是：

> **需求已经形成，但 Hach / iMS 仍有机会影响解决方案、技术路线、技术规格和采购路径的时候。**

---

# 3. 重新定义“早”的含义

这是硬性规则。

## EARLY / GOOD 不能按“距离开标还有多少天”判断。

例如：

> 还有 20 天开标

不代表：

> Entry Window = GOOD。

真正的判断标准是：

> **Hach / iMS 是否仍然能够影响需求、方案或技术规格？**

---

## EARLY

典型状态：

- 客户痛点刚出现
- 新法规刚形成客户级影响
- 扩建/技改意向
- 项目规划
- 立项
- 可研
- 环评
- 初步方案
- 数字化规划
- 运维改善计划
- Installed Base 问题暴露
- 设计院尚未锁定
- EPC 尚未锁定
- Instrument Specification 尚未形成

此时 Hach / iMS 有较大空间影响方案。

---

## GOOD

典型状态：

- Basic Design
- 设计院已介入但规格未冻结
- EPC 已介入但 Instrument Package 未锁定
- 技术交流阶段
- 技术规格编制阶段
- 采购策略正在形成
- Vendor List 尚可影响

关键仍然是：

> **技术方案 / Specification 仍然可影响。**

---

## LATE

典型状态：

- 正式招标已经发布
- 技术规格已经写入招标文件
- EPC 总包已经开始招标
- Instrument Package 已经基本定义
- Vendor List 已冻结

即使：

> 还有 20–30 天才开标，

通常也应该判断：

**LATE**

而不是 GOOD。

---

## CLOSED

典型状态：

- EPC 已中标
- Instrument Package 已采购
- Vendor 已确定
- Installation
- Commissioning
- 项目即将投运

除非存在明确的：

> Installed Base / Service / iMS follow-on opportunity。

# 4. 新增核心指标：Influence Window

每条 Lead 必须增加：

## Influence Window / 影响窗口

回答：

> **Hach / iMS 现在还能影响什么？**

必须从以下选择：

### HIGH
仍可影响：

- Solution Architecture
- Water Treatment Concept
- Monitoring Strategy
- Instrument Specification
- Digitalization Requirement
- Vendor List
- iMS Requirement

### MEDIUM
主要还能影响：

- Instrument Selection
- Brand Selection
- Package Specification
- EPC Vendor Recommendation

### LOW
只能：

- 参与已经形成的采购
- 争取品牌替换
- 通过 EPC 进入

### NONE
方案、规格、供应商基本已经确定。

# 9. iMS Fit 必须基于客户问题

不要问：

> “iMS 理论上能不能用于这个项目？”

必须问：

> **“这个 Account 是否已经出现 iMS 能解决的问题？”**

输出必须遵循：

**客户问题 → iMS 能力 → 商业价值**

例如：

> 多厂区 + 大量在线仪表 + 人工巡检  
> → iMS 集中设备状态管理  
> → 减少巡检工作量，提高仪表可用率。

而不是：

> “iMS 可用于数据监控、告警和报表。”

禁止泛化产品描述。

# 10. Lead Type 必须明确分类

每条 Lead 增加：

## Opportunity Type

只能从以下选择：

### iMS Lead
已经存在客户级 iMS Demand Signal。

### Instrument + iMS Lead
仪表采购机会和 iMS 需求同时成立。

### Instrument Lead
有 Hach Instrument Opportunity，但没有发现 iMS Demand。

### Early Strategic Lead
尚未形成明确采购，但存在 Early Trigger + High Influence Window，值得提前培育。

### Tender Monitoring
已经进入招标，只能监控采购机会。

### Installed Base Future Lead
当前项目已晚，但未来可能形成 iMS / Service Opportunity。

### Not Qualified
不值得继续投入。

# 11. Tender Monitoring 不得占据 Radar 主榜

如果已经：

> 正式发布 EPC / Equipment Tender，

默认：

**Opportunity Type = Tender Monitoring**

除非能够证明：

> Instrument / iMS Specification 仍然可以影响。

Tender Monitoring：

- 可以保留；
- 可以供销售参考；
- 但不要进入“今日最值得关注机会”Top List；
- 不应挤占 Early Signal 的研究资源。

# 16. 最重要的 Quality Gate

每条准备进入 Top Opportunities 的 Lead，在发布前必须问：

> **如果销售今天知道这条信息，他还能影响什么？**

> “赶紧看看能不能投标。”

那么它不是 Radar 的核心 Opportunity。

它属于：

> **Tender Monitoring。**

如果答案是：

> “现在可以找到 Owner / Design Institute / EPC，
> 在方案和规格形成前影响需求。”

这才是：

> **Radar Opportunity。**

# 17. Radar North Star

> **Radar 的价值不是提前看到招标，而是在客户需求已经出现、技术规格尚未冻结的时候发现机会。**

> **iMS Radar 的价值不是寻找写着“采购 iMS”的项目，而是提前发现客户正在形成的仪表运维、数据管理、合规和数字化问题。**

**Early Signal > Tender Signal**

**Customer Problem > Product Keyword**

**Installed Base Pain + Operational Trigger 与 New CapEx 同等重要**

**Qualification > Information Collection**
