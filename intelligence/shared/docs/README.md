## Import boundary

DuMate prompt/spec files are preserved with their market. Exported reports and scripts are kept under each market's `archive/dumate-2026-09-29/` directory and are reference snapshots, not production feeds. Platform-specific runtime notes and full personal memory files are excluded; no credentials are stored here.
