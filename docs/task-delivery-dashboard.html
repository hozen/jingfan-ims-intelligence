Delivery Standard · 每个 Task 的 Definition of Done

以后不再只交代码或文档；每个阶段必须留下客户可以理解、审阅和继续使用的成果。

RULE

1 · Customer outcome

客户能用一句话说清楚：这一步新增了什么决策能力、节省了什么时间、降低了什么风险。

2 · Visible artifact

至少一个可打开、可阅读、可演示的产物：Lead pack、mapping report、evidence brief、decision summary 或 dashboard。

3 · Evidence of correctness

测试结果、样例输入输出、兼容性结果、已知限制和失败案例必须可见。

4 · Scope honesty

明确哪些完成、哪些未完成、哪些不应在本 Task 做，防止“看起来很完整”但不能交付。
